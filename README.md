# Elavate Multi-Collagen Superblend Website

A high-fidelity e-commerce experience for **elavate® Multi Collagen Superblend**, built with React, TypeScript, Vite, and Tailwind CSS.

## 🌟 Key Features

- **Product Selector & Customizer**: Choose package size (1, 2, or 3 Pouches) with auto-applied discount savings and free gift add-ons (Electric Frother, Shaker Bottle).
- **Interactive Flavor & Wellness Quiz**: Guided quiz to help customers discover their ideal collagen flavor and personalized routine.
- **Cart Drawer**: Sliding cart drawer with dynamic subtotal calculations, coupon code support (e.g. `GLOW10`), gift tier progress bar, and checkout flow.
- **High Quality Visual Assets**: Local high-resolution product photography for **Chocolate**, **Salted Caramel**, **Vanilla**, **Berry**, and **Unflavoured** options.
- **Ingredients & Benefits Showcase**: Clean breakdown of 5 types of collagen (I, II, III, V, X), Hyaluronic Acid, Vitamin C, and Biotin.
- **Social Proof & Customer Reviews**: Customer rating metrics and real product testimonials.
- **FAQ Accordion**: Answers to common queries regarding dosage, taste, and dietary compatibility.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/elavate-collagen.git
   cd elavate-collagen
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

The output will be placed in the `dist/` directory, ready to deploy to Vercel, Netlify, Cloud Run, or any static hosting service.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (fka Framer Motion)
- **Icons**: Lucide React
